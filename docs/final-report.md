# Final Report

## Project Title
Urban Waste Classification – Intelligent IoT System

## Team Members
- Samarth Gupta
- Yash Kumar
- Prince Raikwar

## Description
This project implements an automated waste classification system using sensors and motors controlled by Arduino.

## Working
- IR sensor detects waste.
- Servo motor opens lid.
- Rain sensor identifies waste type.
- Stepper motor directs waste.

## Results
The system successfully classifies waste into wet and dry categories.

## Conclusion
The project demonstrates the use of IoT in smart waste management systems.
