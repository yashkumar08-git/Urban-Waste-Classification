# System Design

## Objective
To describe the design structure of the smart waste classification system.

## Components
- Arduino Uno (Controller)
- IR Sensor (Detection)
- Servo Motor (Lid Control)
- Rain Sensor (Classification)
- Stepper Motor (Waste Direction)

## Design Explanation
All sensors and motors are connected to the Arduino, which acts as the central control unit.

## Result
A complete system design for automated waste classification is achieved.
